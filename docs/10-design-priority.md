# 10. 디자인 우선순위

> 개발 일정([09-weekly-schedule.md](./09-weekly-schedule.md))과 연동한 **디자인 산출물 우선순위** 정리  
> **원칙:** 개발이 막히지 않는 것 → 플레이가 읽히는 것 → 메타·확장 → 폴리시·마케팅

---

## 우선순위 등급

| 등급 | 의미 | 대응 시기 |
|------|------|-----------|
| **P0** | 개발 착수 전·즉시 필요. 없으면 코딩 블로킹 | W01 ~ W05 |
| **P1** | 코어 루프 플레이 가능. 없으면 M2·M3 지연 | W06 ~ W13 |
| **P2** | 메타·확장 시스템. M4·M5 전 필요 | W14 ~ W22 |
| **P3** | 폴리시·출시 품질 | W23 ~ W26 |
| **P4** | 스토어·마케팅 | W27 ~ W31 |

---

## 한눈에 보는 우선순위 맵

```
P0  비주얼 가이드 · 맵 타일 · 캐릭터 실루엣 · HUD 와이어 · 조리 플로우 UX
         ↓
P1  손님/기구/음식 아이콘 · Day·메뉴·결산 UI · 레시피 수치 시트
         ↓
P2  메타·특성 트리 UI · 시너지 표시 · 인테리어 · 알바 · Rank 화면
         ↓
P3  UI 통일 · 튜토리얼 · 사운드 · 아트 2차 · 밸런스 최종
         ↓
P4  스토어 키비주얼 · 스크린샷 · 트레일러 · 로고
```

## P0 — 개발 블로킹 (W01 ~ W05, 9월)

### 1. 비주얼 아트 가이드 (최우선)

| 항목 | 산출물 | 비고 |
|------|--------|------|
| 픽셀 규격 | 타일 **16×16** 또는 **32×32** 중 1종 확정 | 전 에셋 통일 |

| 캐릭터 | 1프레임 실루엣 (플레이어·손님) | 4방향 or 2방향 |
| UI 톤 | HUD 색·폰트 후보 1종 | 임시라도 통일 |

## 인력이 1인일 때 권장 순서

개발과 **겹치지 않게** 밤·주말에 밀어넣을 디자인 순서:

1. **9월 1주차:** 비주얼 가이드 + 타일 placeholder (개발 W01~W02)
2. **9월 2~3주차:** 손님 1종 + HUD 와이어 (W03~W04)
3. **10월:** 메뉴판·결산 UI 목업 (W07~W08) ← **가장 중요한 UI**
4. **11월:** 요리·카테고리 아이콘 + Recipe 시트 (W10~W11)
5. **12월:** 메타·특성 트리 UI (W14~W16)
6. **1월:** 시너지·인테리어 (W18~W21)
