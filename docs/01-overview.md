# 01. 게임 개요

## 장르 & 컨셉

| 항목 | 내용 |
|------|------|
| **장르** | 도트 그래픽 요리·경영 시뮬레이션 + 로그라이트 |
| **참고** | 뱀파이어 서바이벌식 메타 성장 루프 |
| **회차 단위** | 30일 (Day) |
| **핵심 긴장** | 손님 대기 시간 게이지 — 초과 시 이탈, 평점·명예 차감 |

## 플레이어 목표

- **단기:** 하루·한 회차 동안 손님을 처리하고 매출·만족도를 유지
- **장기:** 30일 종료 시 Rank 산정 → 영구 재화 획득 → 다음 회차에서 더 나은 빌드로 재도전

---

## 메인 게임 루프

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  준비 단계   │ →  │  영업 단계   │ →  │  결산 단계   │
│ (Day 시작 전)│    │ (Day 진행)  │    │ (Day 종료)  │
└─────────────┘    └─────────────┘    └─────────────┘
                                              │
                                              ▼
                                    ┌─────────────────┐
                                    │ 30일차?          │
                                    │  No → 다음 Day   │
                                    │  Yes → 최종 결산  │
                                    └─────────────────┘
                                              │
                                              ▼
                                    ┌─────────────────┐
                                    │ 메타 성장        │
                                    │ (레시피·특성 해금)│
                                    └─────────────────┘
                                              │
                                              ▼
                                         다음 회차
```

### 준비 단계 (Day 시작 전)

| 요소 | 설명 |
|------|------|
| 메뉴판 구성 | 판매할 요리 슬롯 지정 (변경 시 골드 수수료 발생) |
| 인테리어/테이블 | 가게 배치, 테이블 수·위치 조정 |
| 특성 선택 | 이번 회차에 적용할 패시브 특성 선택 |

### 영업 단계 (Day 진행)

```
손님 입장 → 주문 수령 → 요리 제작 → 제공 → 식사/결제 → 퇴장
                              ↑
                   (대기 시간 초과 시 "막 돌아간 손님")
                   → 최종 평점·명예 점수 차감
```

### 결산 단계 (Day 종료)

- 일일 매출 확인
- 손님 만족도 확인
- 놓친(이탈) 손님 수 확인
- 가게 평점 확인
- 간단한 정비 (다음 날 준비)

### 최종 결산 (30일차 종료)

| 항목 | 설명 |
|------|------|
| 최종 획득 골드 | 회차 누적 매출 |
| 누적 명예 | 회차 동안 획득한 명예 포인트 |
| 총 놓친 손님 | 이탈 손님 누적 |
| 최종 가게 평점 | Rank 산정 기준 |
| **Rank 등급** | S/A/B/C 등 |
| **영구 재화** | 다음 회차 해금·성장에 사용 |

## 한 줄 요약

> **30일 한정 가게 운영 → 손님 대기·조리·메뉴 전략으로 버티고 → 회차마다 레시피·특성을 해금해 더 강한 빌드로 재도전하는 도트 요리 로그라이트**
