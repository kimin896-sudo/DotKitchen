# 06. 메타 성장 & 특성 트리

## 성장 흐름

```
30일 회차 종료
      │
      ▼
Rank 산정 + 명예/영구 재화 획득
      │
      ├──→ 레시피 해금 (카테고리별 고급 메뉴)
      ├──→ 특성(패시브) 해금
      └──→ 카테고리 전용 장비 해금
      │
      ▼
다음 회차 시작 (더 강한 빌드)
```

---

## 카테고리별 특성 트리

### 한식 (Korean)

**해금 순서:** 비빔밥 → 김치찌개 → 불고기 정식 → 갈비찜

| 특성 | 효과 |
|------|------|
| `육수 밑작업` | 찌개/국물류 요리의 사전 준비 시간 단축 |
| `따뜻한 정` | 한식 메뉴 주문 손님의 대기 인내심 게이지 감소 속도 완화 |

---

### 양식 (Western)

**해금 순서:** 알리오 올리오 → 시저 샐러드 → 안심 스테이크 → 랍스터 구이

| 특성 | 효과 |
|------|------|
| `고급 시즈닝` | 양식 요리 판매 단가 일정 비율 상승 |
| `화력 조절` | 불 사용 조리 시간(굽기 등) 단축 |

---

### 중식 (Chinese)

**해금 순서:** 짜장면 → 짬뽕 → 탕수육 → 전신 마라탕

| 특성 | 효과 |
|------|------|
| `화로 숙련` | 웍/화구 연속 조리 시 속도 대폭 증가 |
| `대량 구매` | 중식 재료 구매 비용 할인 |

---

### 패스트푸드 & 카페 (Fast Food & Cafe)

**해금 순서:** 아메리카노/감자튀김 → 에이드/치즈버거 → 수제버거/디저트

| 특성 | 효과 |
|------|------|
| `초스피드 포장` | 포장·배달 준비 시간 대폭 단축 |
| `원두/재료 추출` | 음료·패스트푸드 조리 입력 횟수 감소 또는 즉시 완료 |

---

## 공용 특성 트리 (경영/매장 강화)

카테고리 무관, 매장 전반을 강화하는 패시브.

| 특성 | 효과 |
|------|------|
| 사장 이동속도 | 플레이어 이동 빨라짐 |
| 손질/집기 속도 | 전처리·기구 사용 시간 단축 |
| 알바 일당 할인 | 알바생 고용 비용 절감 |
| 알바 서빙 속도 | 알바생 음식 제공·테이블 정리 속도 |
| 손님 인내심 기초값 | 모든 손님 대기 게이지 초기값 증가 |
| 메뉴 교체 수수료 할인 | 준비 단계 메뉴 변경 골드 절감 |
| 테이블 추가 할인 | 인테리어·테이블 배치 비용 절감 |

## 회차별 진행 체감

### 1회차 — 생존

- **해금 메뉴:** 아메리카노, 샌드위치 등 기본 메뉴
- **목표:** 30일 버티며 명예 포인트 획득
- **전략:** 스피드형(A), 이탈 손님 최소화

### 2회차 — 속도 특화

- **해금:** 중식 트리 → 짜장면, 짬뽕
- **특성:** `화로 숙련`, `대량 구매`
- **전략:** 빠른 순환 맛집, 중식 연속 조리 버프 활용

### 3회차 — 고수익

- **해금:** 양식 고급 → 스테이크, 랍스터
- **특성:** `고급 시즈닝`, `화력 조절`
- **전략:** 대형 매장 + 알바 다수 고용, 하이엔드 홀 전용(B)
