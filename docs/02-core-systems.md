# 02. 핵심 시스템

## 1. 메뉴판 및 세팅 시스템

### 기본 규칙

- 회차 시작 전(또는 Day 진행 중) **판매할 요리 슬롯**을 지정
- **메뉴 변경 시 골드 수수료** 발생 → 전략적 메뉴 선택 필요
- 고려 요소: 재료 비용, 조리 시간, 카테고리 세트 시너지

### 메뉴 슬롯

- 기본 가정: **4슬롯**
- 카테고리를 섞어 하이브리드 세트 효과 구성 가능
- 자세한 카테고리·시너지는 [03-categories-and-synergy.md](./03-categories-and-synergy.md) 참고

## 2. 손님 메커니즘 (메인 허들)

### 대기 시간 게이지

- 모든 손님에게 **대기 시간 게이지** 존재
- 게이지가 가득 차면 → **"막 돌아간 손님"** 으로 카운트
- 이탈 손님은 **최종 평점**과 **명예 점수**에 불리하게 작용

### 손님 AI — FSM (유한 상태 머신)

```
                    ┌──────────────────────────────────┐
                    │                                  │
                    ▼                                  │
  입장 → 대기 → 주문 → 음식 대기 → 식사 → 결산 → 퇴장
                    │                                  │
                    └──── (타임아웃) ──→ 이탈 ─────────┘
```

| 상태 | 설명 |
|------|------|
| **입장** | 가게 입구에서 등장, 좌석 탐색 |
| **대기** | 빈 테이블 없을 때 대기 (게이지 감소 시작) |
| **주문** | 착석 후 메뉴 주문 |
| **음식 대기** | 요리 제공까지 대기 (게이지 감소) |
| **식사** | 음식 수령 후 식사 |
| **결산** | 계산·팁 지불 |
| **퇴장** | 정상 퇴장 |
| **이탈** | 대기 게이지 만료 → "막 돌아간 손님" |

### 구현 시 고려사항

- 손님 유형별 데이터는 SO/CSV로 관리 (인내심, 선호 메뉴, 팁 확률 등)
- Grid/Tilemap 기반 동선으로 입장·착석·퇴장 경로 관리

## 3. 로그라이트 메타 성장

뱀파이어 서바이벌 방식 — **회차 종료 후 획득한 자원으로 영구 성장**

### 성장 축

| 축 | 설명 | 소모 자원 |
|----|------|-----------|
| **요리 해금** | 고득점·고난도 레시피 해금 | 명예/포인트 |
| **특성(패시브)** | 조리 속도, 이동 속도, 손님 인내심 등 | 명예/포인트 |
| **장비 해금** | 카테고리 전용 주방 기구 | 명예/포인트 |

### 대표 특성 예시

| 특성 | 효과 |
|------|------|
| 조리 속도 증가 | 요리 완성 시간 단축 |
| 이동 속도 증가 | 사장·알바 이동 빨라짐 |
| 손님 인내심 증가 | 대기 게이지 감소 속도 완화 |
| 메뉴 변경 수수료 감소 | 준비 단계 메뉴 교체 비용 절감 |
| 테이블 추가 할인 | 인테리어 비용 절감 |

자세한 특성 트리는 [06-meta-progression.md](./06-meta-progression.md) 참고.

## 4. 재화 체계

| 재화 | 범위 | 용도 |
|------|------|------|
| **골드** | 회차 내 | 재료 구매, 메뉴 변경 수수료, 알바 일당, 인테리어 |
| **명예 포인트** | 회차 → 영구 | 레시피·특성·장비 해금 |
| **영구 재화** | 영구 | 30일 Rank 기반 획득, 메타 성장 가속 |
