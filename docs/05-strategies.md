# 05. 플레이 전략 & 빌드 가이드

## 전략 A — 배달/포장 싹쓸이 (스피드형)

| 항목 | 내용 |
|------|------|
| **메뉴** | 아메리카노 + 샌드위치 + 감자튀김 |
| **카테고리** | 카페 + 패스트푸드 |
| **특징** | 주방에 불을 때울 필요 없이 즉시 내보냄 |
| **장점** | 대량 판매, 높은 회전율, 막 돌아가는 손님 거의 없음 |
| **단점** | 접시당 단가 낮음 → 양으로 승부 |
| **추천 특성** | `초스피드 포장`, `원두/재료 추출`, 이동 속도 |

---

## 전략 B — 하이엔드 홀 전용 (고수익형)

| 항목 | 내용 |
|------|------|
| **메뉴** | 스테이크 + 파스타 + 파르페 |
| **카테고리** | 양식 + 카페 |
| **특징** | 조리 시간 길어 주방·알바 부담 큼 |
| **장점** | 몇 접시만 팔아도 목표 금액 달성 가능 |
| **단점** | 알바생 고용 필수, 대기 시간 관리 어려움 |
| **추천 특성** | `고급 시즈닝`, `화력 조절`, 손님 인내심 |

---

## 전략 C — 하이브리드 안정형

| 항목 | 내용 |
|------|------|
| **메뉴** | 김치찌개(사전 준비) + 아메리카노(빠른 포장) + 스테이크(메인 수익) |
| **카테고리** | 한식 + 카페 + 양식 |
| **특징** | 고단가 1 + 스피드 2로 손님 대기 시간 방어 |
| **장점** | 수익·속도·안정성 균형 |
| **단점** | 세트 시너지 완전 발동 어려움 |
| **추천 특성** | `육수 밑작업`, `따뜻한 정`, 이동 속도 |

---

## 빌드 선택 가이드

| 상황 | 추천 전략 |
|------|-----------|
| 1회차, 자원 부족 | **A (스피드형)** — 기본 메뉴로 안정적 명예 획득 |
| 중식 트리 해금 후 | **A 변형** — 짜장·짬뽕 + 화력 특성으로 빠른 순환 |
| 양식 고급 해금 후 | **B (고수익형)** — 스테이크 전문점 |
| 알바·테이블 충분 | **B 또는 C** — 고단가 메뉴 활용 |
| 배달/포장 주문 많을 때 | **A (디저트 배달)** — 카페2 + 패스트2 |
| 평점·명예 중시 | **C (안정형)** — 이탈 손님 최소화 |
