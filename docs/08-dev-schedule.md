| 항목 | 내용 |
|------|------|
| **기간** | 약 **7개월** (213일) / **30주** |

## Phase별 상세 일정

### Phase 0 — 기반 세팅 (9/1 ~ 9/7, 1주)

| 작업 | 내용 |
|------|------|
| 프로젝트 | URP/2D, 폴더 구조, 씬 구조, Git 워크플로 |
| 아키텍처 | 싱글톤 vs 서비스 로케이터, 이벤트 버스 방향 확정 |
| 에셋 | 임시 도트 타일/캐릭터 placeholder |
| 문서 | 기획 docs ↔ 구현 체크리스트 동기화 |

**완료 기준:** 빈 맵에서 플레이어가 이동하고, 씬 전환이 된다.

---

### Phase 1 — 프로토타입 (9/8 ~ 9/30, 약 3주) → **M1**

| 주 | 작업 |
|----|------|
| W1 | Grid/Tilemap, 충돌, A* 또는 단순 그리드 패스파인딩 |
| W2 | 손님 FSM (입장→대기→주문→음식대기→식사→퇴장/이탈) |
| W3 | 요리 1~2종 조리·서빙, 대기 게이지 UI, 내부 플레이테스트 |

**완료 기준:** 손님이 들어와 주문하고, 요리를 주면 먹고 나가거나 게이지로 이탈한다.

**리스크:** 동선/착석 로직이 예상보다 복잡 → 테이블 고정 배치로 단순화 허용.

---

### Phase 2 — Day 코어 루프 (10/1 ~ 10/31, 4주) → **M2**

| 주 | 작업 |
|----|------|
| W1 | Day 상태 머신 (준비/영업/결산), 시간·손님 스폰 |
| W2 | 메뉴판 슬롯, 메뉴 변경 수수료, 골드 경제 기초 |
| W3 | 결산 UI (매출·만족도·이탈·평점) |
| W4 | 여러 Day 연속 플레이, 밸런스 러프 패스 |

**완료 기준:** 준비→영업→결산을 3일 이상 끊김 없이 플레이 가능.

---

### Phase 3 — 데이터 & 콘텐츠 (11/1 ~ 11/30, 4주) → **M3**

| 주 | 작업 |
|----|------|
| W1 | Recipe / Customer / Ingredient / Equipment SO 스키마 확정 |
| W2 | 5카테고리 × 기본~중급 메뉴 데이터 입력 (고급은 stub) |
| W3 | 4스탯 조리 파이프라인 (전처리/불질/서빙/신선도) |
| W4 | 카테고리별 전용 기구 게이트, 플레이 밸런스 1차 |

**완료 기준:** 카테고리별로 최소 2종 이상 요리를 실제로 조리·판매할 수 있다.

**병행:** 도트 아트(주방 기구, 손님 2~3종) placeholder → 1차 교체.

---

### Phase 4 — 메타 성장 (12/1 ~ 12/31, 4주) → **M4**

| 주 | 작업 |
|----|------|
| W1 | 30일 루프, 최종 결산, Rank 산정 공식 |
| W2 | 명예/영구 재화, 세이브/로드 (회차 간) |
| W3 | 레시피 해금 UI + 특성 트리 **1개 카테고리** 완성 |
| W4 | 1→2회차 체감 플레이테스트 (성장이 느껴지는지) |

**완료 기준:** 30일 종료 → 명예로 메뉴/특성 해금 → 새 회차에서 해금이 반영된다.

**연말 버퍼:** 12/24~1/1은 속도 저하 가정. 핵심만 마무리.

---

### Phase 5 — 시스템 확장 (1/1 ~ 1/31, 4주) → **M5**

| 주 | 작업 |
|----|------|
| W1 | 세트 시너지 + 하이브리드 빌드 버프 계산 |
| W2 | 알바생 AI (서빙/정리 최소 행동) |
| W3 | 인테리어/테이블 배치 (그리드 배치 + 비용) |
| W4 | 특성 트리 전체(카테고리 4 + 공용), 장비 해금 |

**완료 기준:** 전략 A/B/C 빌드를 의도적으로 플레이할 수 있다.

**컷 후보 (일정이 밀리면):** 알바 AI 고도화, 인테리어 자유도 → 고정 레이아웃 + 테이블 수만.

---

### Phase 6 — 콘텐츠·밸런스·폴리시 (2/1 ~ 2/28, 4주) → **M6**

| 주 | 작업 |
|----|------|
| W1 | 고급 메뉴·특성 수치 밸런스, 난이도 곡선 (Day 1~30) |
| W2 | UI/UX 전면 정리 (준비/영업/메타 화면) |
| W3 | 튜토리얼 / 온보딩 (첫 회차 가이드) |
| W4 | 사운드·이펙트·도트 아트 2차 교체, 옵션(해상도/키) |

**완료 기준:** 신규 플레이어가 튜토리얼 없이(또는 짧게) 30분 이상 플레이 가능.

---

### Phase 7 — Soft Lock & Gold (3/1 ~ 4/1, 약 4.5주)

| 구간 | 날짜 | 작업 |
|------|------|------|
| Soft Lock | 3/1 ~ 3/15 | **신규 기능 금지.** 크리티컬 버그, 밸런스 핫픽스만 |
| QA | 3/8 ~ 3/25 | 체크리스트 QA, 세이브 손상, 성능(손님 다수), 빌드 파이프라인 |
| 스토어 준비 | 3/15 ~ 3/28 | 트레일러 숏, 스크린샷, 스토어 텍스트, 위시리스트 |
| Gold Candidate | **3/28 ~ 4/1** | 최종 빌드 태깅, 배포용 패키지 |

**4/1 완료 기준 (Definition of Done):**

- [ ] 30일 × 다회차 메타 루프 정상 동작
- [ ] 5카테고리 메뉴·시너지·특성 트리 플레이 가능
- [ ] 세이브/로드 안정
- [ ] 튜토리얼 또는 인게임 가이드 존재
- [ ] Windows 스탠드얼론 빌드 배포 가능
- [ ] 알려진 크리티컬 버그 0건

## 인력·역할 권장 (현실적)

| 역할 | 최소 | 이상적 |
|------|------|--------|
| 프로그래머 | 1 | 1~2 (코어 / UI·툴) |
| 도트 아트 | 본인 병행 or 에셋 | 파트타임 1 |
| 사운드 | 무료/에셋 | 외주 1~2주 |
| QA | 본인 + 지인 | 3월에 집중 테스터 3+ |

**아트 병행 팁:** 9~11월은 placeholder, **2월에 일괄 교체**하면 일정 리스크가 가장 낮음.

## 리스크 & 완충

| 리스크 | 영향 | 대응 |
|--------|------|------|
| 손님 AI·동선 복잡도 | Phase 1~2 지연 | 고정 웨이포인트, 테이블 고정 배치 |
| 콘텐츠 양(메뉴·특성) | Phase 3~5 지연 | 고급 메뉴 stub, 특성 수치만 먼저 |
| 알바 AI | Phase 5 지연 | **1순위 컷** — 사장 혼자 운영으로 출시 |
| 밸런스 붕괴 | Phase 6 지연 | 데이터 테이블만으로 조정 가능 구조 유지 |
| 연말/설 휴가 | 12~1월 속도↓ | M4를 12월 중순에 조기 잠금 |

**버퍼:** Soft Lock 2주 + Gold 전 1주 = **약 3주 일정 여유**.  
이 여유를 침범하면 기능을 자르고 **출시 범위를 축소**한다 (아래 컷리스트).
